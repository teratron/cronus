## Overview

Strategic plan for maturing nodus from an in-tree vendored crate to an independently extractable, production-ready workflow-language library. The arc runs: spec completeness → library hardening → extraction readiness → observability & extension framework → portability → testing → capability manifest (LP-8). Each new contract spec is implemented, then its L2 spec is synced to the realized Rust shape.

Execution mode: **Sequential** (spec correctness must precede hardening; hardening must precede extraction).

> **Sync (v1.24.0, 2026-07-30):** resolved the one mechanical `SYNC_GAP` (PLAN basis v1.0.65 → v1.0.66, from Phase 20's Track C spec reconciliation — the only two changed registry rows were the ones that phase itself corrected) and opened **Phase 21 — Compact-Form Round-Trip Fidelity for Control Flow (NL-6)**, a 7-task / 4-track (A–C, T) Sequential conformance phase. **Third instance of the Phase 17 / Phase 20 C12.1 shape, and the largest.** `Transpiler::to_nodus` silently **drops every control-flow step**: `nodus_step` matches only `Stmt::Command` and `Stmt::Comment`, so all seven other `Stmt` variants hit a `_` catch-all returning `""`, and the caller's `if !line.is_empty()` skips the step entirely. Three Stable specs mandate the opposite — `l1-nodus-language` NL-6 (*"compact → human → compact must produce an **AST-equal** result"*), `l2-nodus-runtime` §3/§4.5 (*"compact, **lossless**"*), and `l2-nodus-control-flow` §3/§4 (*"**each new node gains compact and human emitters**"*). **Proved empirically at plan time, not inferred from a code read** (the Phase-20 Track-B lesson, applied): a temporary probe transpiled the Phase-20 `?SWITCH` fixture and re-parsed it — `orig steps=2 reparsed steps=1`, with the entire `?SWITCH` step absent from the emitted `@steps:` block; probe reverted after observation. Two structural findings explain how it survived this long: the emitter asymmetry is **total** (human side has 7 emitters with full control-flow coverage, compact side has 2 with none — the spec's "each new node gains compact and human emitters" is half-true, the human half), and **the guard the spec claims exists was never built** — `l2-nodus-runtime` §3 asserts a round-trip test in `workflows.rs` verifying AST equality, but grepping that file yields only the `TranspileMode::Compact` dispatch line. The round-trip tests that *do* exist (`parity.rs`) assert only `ast2.header.name`, so a dropped step is invisible to them — the Phase-17 pattern ("the one construct never tested end-to-end is the one that doesn't work end-to-end") one level up. Scope held to the real violation: three further round-trip oddities the probe surfaced (`core: schema.nodus` → `schema`, injected `mode: production`, `@err:` raw re-spacing) were each checked and found **AST-stable** — they lose information on the first parse and then reproduce idempotently, so they are not NL-6 violations and are explicitly out of scope, with the `core` truncation recorded as its own Backlog item. This also retires the standing *"normative fixture corpus coverage"* Backlog entry's framing: it was logged as "pure corpus tidying — no defect sits behind this", and there is now a defect behind it, since the corpus is exactly what the round-trip harness sweeps. Needs **no new spec** (C12.1). The remaining Backlog (NL-11…NL-19, NL-21, LP-17/18/19, parity clusters, the lexical-scoping design pass) stays design-blocked pending L2 realization specs.
